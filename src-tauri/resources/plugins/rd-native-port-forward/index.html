⚠ GatewayPorts 提醒
SSH 服务器默认 GatewayPorts no，即使填写 0.0.0.0，sshd 也只会绑定到 127.0.0.1，外部无法访问，浏览器会返回 502。
如需对外访问，请在服务器上设置：
sudo vi /etc/ssh/sshd_config → 添加 GatewayPorts yes → sudo systemctl restart sshd（部分系统为 sudo systemctl restart ssh）
