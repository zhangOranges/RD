# SSH-SFTP 远程文件管理器（Finder 风格）P0 MVP 规格

## Why
依据《SSH-SFTP 远程文件管理器（Finder 风格）产品需求文档 V1.3》，实现 P0 必做 MVP：基于单条 SSH 长连接同时承载 PTY 终端与 SFTP 文件双通道，提供 macOS Finder 风格 UI、终端与文件浏览器目录双向联动、目录记忆能力，全程无内核驱动依赖的轻量化远程文件管理客户端。

## 范围说明
本规格仅覆盖 PRD「五、功能迭代优先级」中的 **P0 必做 MVP** 及 P0 验收直接依赖的能力。以下内容明确不在本期范围：
- P1：拖拽上传下载、传输队列、惰性缓存编辑、多标签、断线自动重连、主机分组、收藏目录、布局记忆
- P2：列表/图标视图、chmod、文件预览、深浅色主题、首次启动引导
- P3：跳板机、端口转发、断点续传、全局搜索

## What Changes
- 新建 Tauri 2.0 + React + TypeScript 桌面应用项目骨架（Vite 构建）
- Rust 通信层：基于 russh 的单 SSH 长连接管理，SFTP 通道常驻、PTY 通道按需创建/销毁
- Finder 风格前端：主机侧边栏、面包屑地址栏、三栏分栏视图文件浏览器
- 地址栏输入 cmd/terminal 唤起内置 Xterm.js 终端，支持直接投递 Linux 命令
- 终端 ↔ 文件浏览器双向目录同步（以服务端执行 pwd 的结果为准，禁止解析用户命令文本）
- 目录记忆：路径缓存按「主机ID+标签ID」键存储，主机级开关（默认开启）、全局开关，失效降级家目录
- 基础 SFTP 操作：目录浏览/进入、新建文件夹、删除、重命名、刷新
- 基础主机管理（增删改、连接）与核心设置（目录记忆全局开关，Ctrl+, 打开设置）

## Impact
- Affected specs: 无（全新项目，无历史规格）
- Affected code: 在 `c:\Users\Administrator\Desktop\remote` 下新建完整项目
  - `src-tauri/`：Rust 侧（SSH/SFTP/PTY 通道、持久化、Tauri 命令）
  - `src/`：React 侧（布局、侧边栏、文件浏览器、地址栏、终端面板、设置页）

## ADDED Requirements

### Requirement: SSH 单连接双通道
系统 SHALL 对每台已连接服务器仅维持一条 SSH 长连接，连接建立后创建常驻 SFTP 通道；PTY 通道 SHALL 在终端面板唤起时按需创建、终端关闭时销毁，两者互不影响，且终端关闭不得中断主连接与 SFTP 服务。

#### Scenario: 密码/私钥连接成功
- **WHEN** 用户选择已保存主机并发起连接
- **THEN** 系统使用密码或 Ed25519/RSA 私钥完成 SSH 握手，建立 SFTP 通道并返回用户家目录

#### Scenario: 终端开关不影响文件通道
- **WHEN** 用户唤起或关闭终端面板
- **THEN** PTY 通道相应创建/销毁，SSH 主连接与 SFTP 文件操作保持可用

#### Scenario: 服务器指纹首次信任
- **WHEN** 首次连接某服务器
- **THEN** 系统记录服务器指纹至本地；后续连接指纹不一致时给出警告

#### Scenario: 连接或认证失败
- **WHEN** 主机不可达或认证失败
- **THEN** 前端展示明确错误提示，不崩溃、不残留通道

### Requirement: Finder 风格三栏文件浏览
系统 SHALL 提供 Finder 风格分栏视图（P0 默认且唯一视图）：左栏上级目录、中栏当前目录、右栏所选目录子内容预览；支持双击进入目录、返回上级、前进/后退、刷新。

#### Scenario: 目录导航
- **WHEN** 用户双击文件夹 / 点击面包屑任一级 / 地址栏输入合法路径回车
- **THEN** 文件浏览器跳转至目标目录，面包屑同步更新

#### Scenario: 相对路径补全
- **WHEN** 地址栏输入相对路径
- **THEN** 自动基于当前目录补全为绝对路径后跳转

#### Scenario: 非法路径拦截
- **WHEN** 输入路径非法或目标目录不存在
- **THEN** 地址栏标红或轻量提示，停留在当前目录，不强制跳转

### Requirement: 地址栏唤起终端与命令投递
#### Scenario: cmd 唤起终端
- **WHEN** 用户在地址栏输入 `cmd` 或 `terminal` 并回车
- **THEN** 底部滑出内置终端面板，终端工作目录与文件浏览器当前目录一致

#### Scenario: 地址栏投递命令
- **WHEN** 用户在地址栏输入非路径内容（Linux 命令）并回车
- **THEN** 系统将该命令投递至内置终端执行；若终端未打开则先自动打开

### Requirement: 终端与文件浏览器双向目录同步（核心约束）
系统 SHALL NOT 通过解析用户 cd 命令文本获取终端工作目录，SHALL 统一通过服务端执行 pwd 获取真实绝对路径。

#### Scenario: 文件浏览器 → 终端
- **WHEN** 文件浏览器切换至新目录
- **THEN** 系统通过 PTY 下发 cd 指令，终端工作目录与之一致

#### Scenario: 终端 → 文件浏览器
- **WHEN** 终端一条命令执行完毕
- **THEN** 系统通过 pwd 获取当前工作目录并推送前端，地址栏与文件列表同步刷新

### Requirement: 目录记忆与路径持久化
系统 SHALL 默认在连接成功后恢复上次浏览目录；开关分全局与主机两级，主机级优先于全局。

#### Scenario: 重连恢复上次目录
- **WHEN** 目录记忆开启且该主机存在历史路径缓存
- **THEN** 连接后自动进入缓存目录，文件浏览器与终端同步

#### Scenario: 缓存目录失效降级
- **WHEN** 缓存目录已在服务器被删除
- **THEN** 自动降级进入用户家目录，前端轻量弹窗提示

#### Scenario: 开关关闭
- **WHEN** 主机级或全局记忆开关关闭
- **THEN** 连接后进入用户家目录

#### Scenario: 路径缓存实时更新
- **WHEN** 文件浏览或终端 cd 导致目录变更
- **THEN** 立即覆盖更新「主机ID+标签ID」对应的缓存；软件重启后缓存保留并可复用

### Requirement: 基础 SFTP 文件操作
系统 SHALL 提供新建文件夹、删除（模态二次确认）、重命名、刷新操作。

#### Scenario: 删除二次确认
- **WHEN** 用户触发删除
- **THEN** 弹出模态确认框，确认后执行删除并刷新列表

#### Scenario: 权限不足
- **WHEN** 对无权限的目录/文件执行操作
- **THEN** 给出明确失败原因提示，不崩溃

### Requirement: 主机管理与凭据安全
系统 SHALL 提供主机新增/编辑/删除/连接；字段包括：唯一 ID、名称、主机地址、SSH 端口、用户名、认证类型（密码/私钥）、目录记忆开关、备注。

#### Scenario: 凭据加密存储
- **WHEN** 用户保存主机密码或私钥
- **THEN** 凭据仅存入系统密钥链（keychain/credential manager），本地配置文件不含任何明文凭据

### Requirement: 核心设置
系统 SHALL 提供设置页（Ctrl+, 打开），至少包含目录记忆全局开关（默认开启）；设置修改无需重启即生效。

## 非功能性要求（P0 验收基线）
- 单 SSH 连接双通道稳定运行；常规目录切换响应 ≤300ms
- 千级文件目录采用虚拟滚动，滚动无明显卡顿
- 目录双向同步延迟 ≤200ms
- 终端交互不阻塞文件浏览
