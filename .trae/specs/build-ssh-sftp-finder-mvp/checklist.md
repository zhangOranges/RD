# Checklist

- [x] `npm run tauri dev` 可正常启动，展示 Finder 风格主界面（侧边栏 + 工具栏 + 三栏内容区 + 状态栏）
- [x] 密码与私钥两种认证方式均可成功连接 SSH 服务器；每主机仅一条 SSH 连接，SFTP 通道常驻
- [x] 服务器指纹首次连接自动信任并本地保存；指纹变化时给出警告
- [x] 终端面板打开/关闭仅创建/销毁 PTY 通道，SSH 主连接与文件浏览不受影响
- [x] 三栏视图双击进入目录、返回上级、前进/后退、刷新均正常；面包屑每级点击跳转正确
- [x] 地址栏路径编辑：绝对/相对路径跳转正确（相对路径自动补全）；非法路径标红且停留原目录
- [x] 地址栏输入 `cmd`/`terminal` 唤起终端，终端工作目录与文件浏览器当前目录一致
- [x] 地址栏输入 Linux 命令可投递至终端执行
- [x] 终端执行 cd 命令完成后，地址栏与文件列表自动更新至新目录（来源为服务端 pwd，而非命令文本解析）
- [x] 文件浏览器切换目录后，终端工作目录同步一致
- [x] 目录记忆：开启时重连自动恢复上次目录；关闭时进入家目录；缓存目录失效时降级家目录并轻量提示
- [x] 重启软件后路径缓存保留并可复用
- [x] 新建文件夹、删除（含模态二次确认）、重命名操作均成功；权限不足场景给出明确提示且不崩溃
- [x] 密码/私钥仅存储于系统密钥链，本地配置文件中无任何明文凭据
- [x] 千级文件目录列表滚动无明显卡顿；终端交互不阻塞文件浏览
