# RD 远程文件管理器 UI 迭代规格（V2.1 双栏版）

## Why
当前 RD 界面为单远程三栏布局（父目录/当前目录/预览），缺少顶部多标签栏、左侧工具菜单与连接信息、右侧功能面板、本地+远程双栏对照操作等核心区域。依据《RD 远程文件管理器（专业双栏版）产品需求文档 V2.1》，需将界面迭代为五区固定式布局，实现本地-远程双栏对照操作、右侧服务器信息/快捷操作/传输队列常驻面板，提升运维专业性与操作效率。

## 范围说明
本规格聚焦 **UI 布局框架迭代**，覆盖 PRD 第一章至第七章的界面结构改造。以下内容不在本期范围：
- 插件系统（PRD 第九章）—— 仅预留工具菜单入口，不实现插件运行时
- 端口转发/远程命令/密钥管理功能逻辑（仅工具菜单入口占位）
- 本地文件栏的完整文件操作（仅浏览+拖拽上传，不支持本地文件右键编辑）
- 文件惰性缓存编辑与冲突检测（P1 功能）
- 多级跳板机、断点续传、全局搜索（P3 功能）

## What Changes
- **BREAKING**：整体布局从「顶部工具栏 + 侧边栏 + 远程三栏 + 底部终端」改为五区布局：「顶部标签栏 + 左侧导航边栏 + 中间双栏工作区 + 右侧功能面板 + 底部终端/状态栏」
- **BREAKING**：FileBrowser 从单远程三栏（父目录/当前目录/预览）改为双栏（本地左栏 + 远程右栏），移除原三栏的父目录列和预览列
- 新增顶部多服务器标签栏，支持标签切换、关闭、新建连接
- 左侧边栏新增：搜索框、工具菜单（SFTP/SSH终端/端口转发/远程命令/密钥管理/插件中心）、底部连接信息概览
- 新增右侧功能面板：服务器信息区、快捷操作区（2×3网格）、传输队列区（上传/下载标签切换）
- 底部终端区新增多终端标签支持
- 底部状态栏新增实时上传/下载速率、网络延迟显示
- 传输通知从 Toolbar 弹出抽屉迁移至右侧面板常驻

## ADDED Requirements

### Requirement: 五区固定式布局框架
系统 SHALL 采用五区固定式布局：顶部全局标签栏、左侧导航边栏、中间主工作区（双栏）、右侧功能面板、底部终端区与状态栏，所有核心功能一屏可达。

#### Scenario: 首屏五区可见
- **WHEN** 应用启动并连接至少一台主机
- **THEN** 顶部标签栏、左侧边栏、中间双栏文件管理器、右侧功能面板、底部状态栏同时可见
- **AND** 终端区可通过快捷键或按钮展开/收起

#### Scenario: 区域尺寸调节
- **WHEN** 用户拖拽侧边栏/右侧面板/终端区的分隔条
- **THEN** 对应区域宽度/高度实时调整，不超出最小/最大限制

### Requirement: 顶部全局标签栏
系统 SHALL 在顶部提供全局标签栏，包含品牌标识「RD」、多服务器标签页、右上角功能按钮。

#### Scenario: 标签页展示
- **WHEN** 用户连接一台主机
- **THEN** 标签栏新增一个标签，显示服务器名称、用户名@IP、连接状态指示灯（绿色=已连接）
- **AND** 标签右侧带关闭按钮

#### Scenario: 标签切换
- **WHEN** 用户点击不同标签
- **THEN** 主工作区、右侧面板、终端区同步切换到对应服务器会话

#### Scenario: 标签关闭
- **WHEN** 用户点击标签关闭按钮
- **THEN** 断开该标签对应主机的连接，关闭标签，切换到相邻标签

#### Scenario: 新建连接
- **WHEN** 用户点击标签栏末尾「+」按钮
- **THEN** 弹出主机选择/新建对话框

#### Scenario: 右键标签菜单
- **WHEN** 用户右键标签
- **THEN** 弹出菜单：关闭当前、关闭其他、关闭右侧、复制连接信息、新建同主机标签

### Requirement: 左侧导航边栏完整结构
系统 SHALL 在左侧边栏自上而下依次提供：连接管理（搜索）、我的连接（主机列表）、分组、工具菜单、底部连接信息概览。

#### Scenario: 搜索主机
- **WHEN** 用户在搜索框输入关键词
- **THEN** 主机列表实时按名称或IP过滤
- **AND** 支持 Ctrl+K / Cmd+K 快速聚焦搜索框

#### Scenario: 工具菜单切换
- **WHEN** 用户点击工具菜单中的某一项（如「SSH 终端」）
- **THEN** 中间主工作区切换到对应功能页面
- **AND** 当前选中项高亮显示

#### Scenario: 连接信息概览
- **WHEN** 某主机已连接
- **THEN** 边栏底部显示该主机的连接信息（主机名、连接时长、SSH版本、加密算法）
- **AND** 底部「会话管理」按钮可展开断开连接等操作

### Requirement: 中间双栏文件管理器
系统 SHALL 在中间工作区提供左右等分双栏布局，左栏为本地文件，右栏为远程文件，支持拖拽互传。

#### Scenario: 双栏浏览
- **WHEN** 用户连接主机并进入 SFTP 模式
- **THEN** 左栏显示本地文件系统当前目录，右栏显示远程文件系统当前目录
- **AND** 两栏各自有独立的面包屑导航和操作按钮

#### Scenario: 拖拽上传
- **WHEN** 用户从本地栏拖拽文件到远程栏
- **THEN** 文件上传至远程当前目录，传输任务进入右侧传输队列

#### Scenario: 拖拽下载
- **WHEN** 用户从远程栏拖拽文件到本地栏
- **THEN** 文件下载至本地当前目录，传输任务进入右侧传输队列

#### Scenario: 远程文件列表表头
- **WHEN** 远程栏显示文件列表
- **THEN** 表头包含：名称、大小、类型、修改时间、权限、所有者
- **AND** 文件夹置顶，支持点击表头排序

#### Scenario: 底部统计栏
- **WHEN** 文件列表加载完成
- **THEN** 本地栏底部显示「X 个文件夹, Y 个文件 | 总大小」
- **AND** 远程栏底部显示相同格式统计 + 「SFTP」标识与锁图标

### Requirement: 右侧功能面板
系统 SHALL 在右侧提供固定宽度功能面板，自上而下包含：服务器信息、快捷操作、传输队列。

#### Scenario: 服务器信息展示
- **WHEN** 主机已连接
- **THEN** 显示主机、用户、协议、端口、系统、在线时长、连接状态
- **AND** 连接状态显示绿色「已连接」文字+圆点
- **AND** 提供「断开连接」红色按钮

#### Scenario: 快捷操作网格
- **WHEN** 面板渲染
- **THEN** 显示 2×3 网格共6个快捷操作按钮：打开终端、新建文本、上传文件、同步目录、权限设置、查找文件
- **AND** 点击按钮触发对应功能

#### Scenario: 传输队列常驻
- **WHEN** 有上传/下载任务
- **THEN** 传输队列区显示任务列表，包含文件名、大小、进度条、速度、暂停/取消按钮
- **AND** 顶部有上传/下载标签切换，标签后带任务数量角标

### Requirement: 底部终端多标签
系统 SHALL 在底部终端区支持多终端标签，每个标签对应一个独立 PTY 通道。

#### Scenario: 新建终端标签
- **WHEN** 用户点击终端标签栏「+」按钮
- **THEN** 在同一SSH连接上创建新PTY通道，新增终端标签

#### Scenario: 终端标签切换
- **WHEN** 用户点击不同终端标签
- **THEN** 终端主体切换到对应PTY会话

#### Scenario: 终端全屏
- **WHEN** 用户点击终端全屏按钮
- **THEN** 终端区扩展占据主工作区全部高度

### Requirement: 底部状态栏增强
系统 SHALL 在底部状态栏右侧显示实时上传/下载速率和网络延迟。

#### Scenario: 传输速率显示
- **WHEN** 有文件正在传输
- **THEN** 状态栏右侧显示「↑ 上传: X MB/s」和「↓ 下载: Y MB/s」
- **AND** 无传输时显示 0 或隐藏

#### Scenario: 网络延迟显示
- **WHEN** 主机已连接
- **THEN** 状态栏右侧显示「● 延迟: Xms」
- **AND** 延迟超过100ms时变色提示

## MODIFIED Requirements

### Requirement: 文件浏览器布局（原三栏→双栏）
原三栏（父目录/当前目录/预览）改为双栏（本地/远程）。本地栏使用 Tauri fs API 浏览本地文件系统；远程栏保留原有 SFTP 操作能力。原预览列的功能由右侧面板的文件信息区或选中后底部详情替代。

### Requirement: 传输通知（原弹出抽屉→右侧常驻面板）
原 Toolbar 中的传输通知铃铛+弹出抽屉改为右侧功能面板中的传输队列常驻区块。Toolbar 中移除传输通知按钮。

### Requirement: 顶部工具栏（原导航+地址栏→标签栏+导航）
原 Toolbar 拆分：窗口控制按钮和导航功能保留在顶部标签栏区域；地址栏移至远程文件栏顶部；传输通知移至右侧面板。

## REMOVED Requirements

### Requirement: 三栏文件浏览器的父目录列和预览列
**Reason**: V2.1 采用本地+远程双栏布局，原三栏的父目录列和预览列不再需要
**Migration**: 父目录导航功能由面包屑栏覆盖；预览功能由右侧面板或双击进入目录替代
