# Checklist

> UI 迭代 V2.1 双栏版验收清单。逐项核对 spec.md 中 ADDED/MODIFIED/REMOVED Requirements 的落地情况。

## 五区布局框架
- [x] 应用启动并连接主机后，顶部标签栏、左侧边栏、中间双栏文件管理器、右侧功能面板、底部状态栏五区同时可见
- [x] 终端区可通过快捷键（Ctrl+`）或按钮展开/收起
- [x] 侧边栏/右侧面板/终端区的分隔条可拖拽调整尺寸，且不超出最小/最大限制

## 顶部全局标签栏
- [x] 标签栏左侧有品牌标识「RD」
- [x] 连接主机后新增标签，显示服务器名称、用户名@IP、连接状态指示灯（绿=已连接）
- [x] 标签右侧带关闭按钮，标签栏末尾带「+」新建连接按钮
- [x] 点击标签切换会话，主工作区/右侧面板/终端同步切换
- [x] 关闭标签时断开对应主机连接并切换到相邻标签
- [x] 右键标签弹出菜单：关闭当前、关闭其他、关闭右侧、复制连接信息、新建同主机标签
- [x] 右上角功能按钮：终端切换、设置入口图标
- [x] 窗口控制按钮（关闭/最小化/最大化）可用且为 macOS 风格

## 左侧导航边栏
- [x] 顶部「连接管理」标题 + 「+」新建连接按钮
- [x] 搜索输入框占位「搜索主机或IP (Ctrl+K)」，输入实时过滤主机列表
- [x] Ctrl+K / Cmd+K 快捷键可聚焦搜索框
- [x] 「我的连接」主机列表按分类分组，每项含状态圆点、名称、用户名@IP
- [x] 分组支持折叠/展开，分组名后带主机数量角标
- [x] 工具菜单含 6 项（SFTP/SSH终端/端口转发/远程命令/密钥管理/插件中心），选中项高亮，点击切换中间工作区
- [x] 底部连接信息概览展示当前主机：主机名、连接时长、SSH版本、加密算法、压缩状态
- [x] 底部「会话管理」按钮可展开断开连接等操作

## 中间双栏文件管理器
- [x] SFTP 模式下左右等分双栏：左本地、右远程
- [x] 本地栏顶部工具栏：路径面包屑 + 前进/后退/刷新按钮，路径可切换输入模式
- [x] 本地栏文件列表表头：名称、类型、修改时间
- [x] 本地栏底部统计栏：文件夹数/文件数/总大小
- [x] 远程栏顶部工具栏：标注「远程: 服务器名」+ 路径面包屑 + 操作按钮组
- [x] 远程栏文件列表表头：名称、大小、类型、修改时间、权限、所有者（六列）
- [x] 远程栏文件夹置顶，支持点击表头升序/降序排序
- [x] 远程栏底部统计栏：文件夹数/文件数/总大小 + 「SFTP」标识与锁图标
- [x] 本地栏拖拽文件到远程栏 → 上传，任务进入右侧传输队列
- [x] 远程栏拖拽文件到本地栏 → 下载，任务进入右侧传输队列
- [x] 远程文件右键菜单保留：打开、重命名、删除、复制路径、下载等原有功能
- [x] 中间列空白处右键显示新建文件/文件夹菜单（原有功能不回归）

## 右侧功能面板
- [x] 服务器信息区：展示主机、用户、协议、端口、系统、在线时长、连接状态
- [x] 连接状态显示绿色「已连接」文字 + 圆点
- [x] 红色「断开连接」主按钮可用
- [x] 快捷操作区：2×3 网格共 6 个按钮（打开终端、新建文本、上传文件、同步目录、权限设置、查找文件）
- [x] 传输队列区：顶部上传/下载标签切换，标签后带任务数量角标
- [x] 传输队列任务列表显示：文件名、大小、进度条、速度、暂停/取消按钮
- [x] 传输队列实时更新（进度、速度、状态）
- [x] 原 Toolbar 中的传输通知弹出抽屉已移除，功能迁移到右侧常驻面板

## 底部终端区
- [x] 终端标签栏：默认「终端 + 序号」，支持「+」新建多个终端标签
- [x] 每个终端标签对应独立 PTY 通道（同一 SSH 连接）
- [x] 切换标签切换 PTY 会话
- [x] 关闭标签销毁对应 PTY 通道，不断开主连接
- [x] 右上角操作按钮：终端全屏、清屏、关闭
- [x] 终端全屏：点击后终端区扩展占据主工作区全部高度
- [x] 终端工作目录与远程文件栏实时双向同步（原有功能不回归）

## 底部状态栏
- [x] 左侧应用全局状态（如「就绪」、版本号、主机计数）
- [x] 右侧实时上传速率「↑ 上传: X MB/s」
- [x] 右侧实时下载速率「↓ 下载: Y MB/s」
- [x] 右侧网络延迟「● 延迟: Xms」，延迟超过 100ms 变色提示

## REMOVED 验证
- [x] 原三栏文件浏览器的父目录列已移除
- [x] 原三栏文件浏览器的预览列已移除
- [x] 原 Toolbar 中的传输通知铃铛/弹出抽屉已移除（App.tsx 不再引用）

- [x] 五区布局一屏可达，无需多级跳转
- [x] 常规目录切换响应无明显卡顿
- [x] 千级文件目录虚拟滚动正常
- [x] 深色专业风格视觉一致
- [x] 全链路冒烟通过：连接 → 标签 → 双栏浏览 → 拖拽传输 → 传输队列 → 终端多标签 → 状态栏 → 断开
